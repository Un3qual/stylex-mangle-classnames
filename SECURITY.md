# Security Policy

## Supported versions

While the package is below version 1.0, security fixes target the latest minor release. Older pre-1.0 versions may not receive backports.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use [GitHub private vulnerability reporting](https://github.com/Un3qual/stylex-mangle-classnames/security/advisories/new) and include:

- The affected package version or commit.
- A minimal reproduction or proof of concept.
- The expected and observed behavior.
- The likely impact and any known mitigations.

The maintainer will acknowledge the report, assess its impact, and coordinate a fix and disclosure through the private advisory. Please allow time for a response before disclosing the issue publicly.
